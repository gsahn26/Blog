오늘은 GitHub를 배웠다 🎉

오늘 모두의연구소 아이펠 수업에서 GitHub를 배웠다. 이름만 들어봤던 Git과 GitHub를 직접 써보니 생각보다 훨씬 재미있었다.

내 컴퓨터에 있는 폴더를 인터넷 저장소에 연결하고, 파일을 올리고, 결국 이 블로그까지 배포했다. 수업이 끝날 때쯤 내 이름이 걸린 페이지가 인터넷에 떠 있는 걸 보니 꽤 뿌듯했다.

오늘 해본 것들

  1. 1
    원격 저장소 연결git remote add origin으로 로컬 폴더와 GitHub 저장소 연결
  2. 2
    첫 커밋git add와 git commit으로 변경 내용 기록
  3. 3
    푸시와 인증git push로 올리고, 이메일 인증 코드로 로그인 마무리
  4. 4
    GitHub Pages 배포저장소 하나로 나만의 블로그 페이지 공개

느낀 점

처음엔 인증 화면에서 이메일을 넣어야 하는지, 코드를 넣어야 하는지 헷갈리기도 했다. 그래도 하나씩 해결해 가는 과정이 퍼즐을 푸는 것 같아 즐거웠다. 앞으로 배우는 내용도 여기에 꾸준히 기록할 생각이다.

아이펠 수업, 정말 재미있었다! 다음 수업도 기대된다.
